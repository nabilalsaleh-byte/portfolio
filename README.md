# Nabil Al-Saleh – Portfolio (INFR3120 Assignment 2)

A personal portfolio website built with Node.js, Express and EJS.

**Live site:** https://nabils-portfolio.onrender.com
**GitHub repo:** https://github.com/nabilalsaleh-byte/portfolio

## Pages
- Home
- About Me
- Projects
- Contact

## How to run locally
1. `npm install`
2. `npm start`
3. Open http://localhost:3000

## Project structure
- `controllers/index.js` – routes for each page
- `views/` – EJS page templates
- `views/partials/` – shared header and footer
- `public/` – CSS, JavaScript and images
